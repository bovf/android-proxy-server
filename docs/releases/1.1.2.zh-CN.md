# Bovf Proxy 1.1.2

[English](https://github.com/bovf/android-proxy-server/blob/v1.1.2/docs/releases/1.1.2.md) | 简体中文

- 普通 HTTP 转发前移除请求头和分块尾部中的代理凭据，保留目标服务器的 Authorization。
- 对慢速 HTTP 客户端暂停/恢复源站读取；客户端断开或出错时关闭暂停的连接。增加有界的真实管线回归测试。
- 以 **Bovf Proxy**（`io.github.bovf.proxy`）与上游并行安装，versionCode 为 **4**。端口仍可配置：HTTP 默认 **8080**、SOCKS5 默认 **1080**；兼容已有无认证辅助工具时可将 HTTP 设为 **3128**。
- 保留上游 master 的熄屏唤醒锁/电池优化豁免支持及本地监听器启动自检。
- 使用分支专用密钥签名。CI 在精确标签测试、APK 证书/标识/版本/源代码提交号检查、校验文件和 GitHub 来源证明验证通过后才发布。发布附件仅有 APK 和 `.sha256`。

仅支持无认证 HTTP 转发、HTTPS/SSH CONNECT 和 SOCKS5 TCP CONNECT；不支持 UDP/BIND，不使用 VpnService、root、跟踪或远程配置。仅限可信网络使用。出站遵循 Android 默认路由，在另一款 VPN 的策略允许时可通过该 VPN。

本次发布未实测真机、熄屏/Doze、热点及并行 VPN 行为。启动检查仅证明本地接受连接。来源证明不等同于独立复现构建。保留上游版权、Apache-2.0 许可证和依赖署名。
