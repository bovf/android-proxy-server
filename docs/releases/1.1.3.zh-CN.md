# Bovf Proxy 1.1.3

[English](https://github.com/bovf/android-proxy-server/blob/v1.1.3/docs/releases/1.1.3.md) | 简体中文

- 修复两处 CI SDK 设置，明确请求 `platform-tools`，而非已移除的旧 `tools` 软件包。`v1.1.2` 工作流在测试/签名前失败，未发布 APK；该标签保持不变。
- 保留 HTTP 请求头/尾部的代理凭据清理、目标服务器 Authorization、有限的响应背压及断开/错误清理，并保留真实管线的 HTTP 与 TLS CONNECT 回归测试。
- **Bovf Proxy**（`io.github.bovf.proxy`），versionCode 为 **5**，可与上游同时安装。HTTP 默认 **8080**、SOCKS5 默认 **1080**；兼容已有无认证辅助工具时可将 HTTP 设为 **3128**。
- 复用分支专用签名密钥。精确标签测试、固定证书/标识/版本/源代码提交号检查、校验文件和 GitHub 来源证明验证通过后才发布。Release 附件仅有签名 APK 和 `.sha256`。
- 保留上游唤醒锁/电池优化豁免支持、本地监听器启动自检、Apache-2.0 许可证及署名。

仅支持无认证 HTTP 转发、HTTPS/SSH CONNECT 和 SOCKS5 TCP CONNECT；不支持 UDP/BIND，不使用 VpnService、root、跟踪或远程配置。仅限可信网络使用。出站遵循 Android 默认路由，在另一款 VPN 的策略允许时可通过该 VPN。

本次发布未实测真机、熄屏/Doze、热点及并行 VPN 行为。监听器自检仅证明本地接受连接。GitHub 来源证明不等同于独立复现构建。
