# Bovf Proxy 1.1.2

English | [简体中文](https://github.com/bovf/android-proxy-server/blob/v1.1.2/docs/releases/1.1.2.zh-CN.md)

- Remove proxy credentials from request headers and chunked trailers before plain-HTTP forwarding, preserving origin Authorization.
- Pause/resume origin reads for slow HTTP clients; close paused connections on client disconnect/error. Add bounded real-pipeline regressions.
- Install alongside upstream as **Bovf Proxy** (`io.github.bovf.proxy`), versionCode **4**. Ports remain configurable: HTTP defaults to **8080**, SOCKS5 to **1080**; set HTTP to **3128** for an existing unauthenticated helper.
- Retain screen-off wake-lock/battery-exemption support and local listener startup checks from upstream master.
- Release signing uses a dedicated fork key. CI gates publication on exact-tag tests, APK certificate/identity/version/source-revision checks, checksum and GitHub provenance verification. APK and `.sha256` are the only release assets.

Unauthenticated HTTP forwarding, HTTPS/SSH CONNECT and SOCKS5 TCP CONNECT only; no UDP/BIND, VpnService, root, tracking or remote configuration. Use trusted networks only. Egress follows Android's default route, including another VPN where permitted by that VPN's policy.

Physical-phone, screen-off/Doze, hotspot and concurrent-VPN behavior have not been tested for this release. Startup checks prove local acceptance only. Provenance is not an independently reproduced build. Upstream copyright, Apache-2.0 license and dependency attribution are retained.
