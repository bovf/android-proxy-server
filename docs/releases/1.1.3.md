# Bovf Proxy 1.1.3

English | [简体中文](https://github.com/bovf/android-proxy-server/blob/v1.1.3/docs/releases/1.1.3.zh-CN.md)

- Fix both CI SDK setup steps to request `platform-tools`, not the removed legacy `tools` package. The `v1.1.2` workflow failed before tests/signing and published no APK; that tag is unchanged.
- Retain proxy-credential stripping from HTTP headers/trailers, origin Authorization, bounded response backpressure and disconnect/error cleanup, with real-pipeline HTTP and TLS CONNECT regressions.
- **Bovf Proxy** (`io.github.bovf.proxy`), versionCode **5**, installs alongside upstream. HTTP defaults to **8080**, SOCKS5 to **1080**; set HTTP to **3128** for an existing unauthenticated helper.
- Reuse the dedicated fork signing key. Exact-tag tests, pinned-certificate/identity/version/source-revision checks, checksum and GitHub provenance verification gate publication. Release assets are the signed APK and `.sha256` only.
- Preserve upstream wake-lock/battery-exemption support and local listener startup checks, Apache-2.0 licensing and attribution.

Unauthenticated HTTP forwarding, HTTPS/SSH CONNECT and SOCKS5 TCP CONNECT only; no UDP/BIND, VpnService, root, tracking or remote configuration. Use trusted networks only. Egress follows Android's default route, including another VPN where permitted by its policy.

Physical-phone, screen-off/Doze, hotspot and concurrent-VPN behavior have not been tested for this release. Listener checks prove local acceptance only. GitHub provenance is not an independently reproduced build.
